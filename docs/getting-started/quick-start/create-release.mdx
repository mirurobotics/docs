To keep things simple, we've provided a [getting-started repository](https://github.com/mirurobotics/getting-started) that contains everything you need to create a release. Follow along with us by cloning the repository.

```bash
git clone https://github.com/mirurobotics/getting-started.git
```

The repository provides the same schemas in two schema languages, [JSON Schema](/cfg-mgmt/concepts/schemas/languages/jsonschema) and [CUE](/cfg-mgmt/concepts/schemas/languages/cue). Use the selector at the top of the page to follow along in either language. If you're unfamiliar with schema languages, we recommend starting with CUE.

## Create a release

With the CLI setup, we are ready to create a release in Miru.

Navigate to the root of the [getting-started](https://github.com/mirurobotics/getting-started) repository and create the release with the schema set you chose for your device's operating system.

<Tabs>
  <Tab title="Linux">
    <CodeGroup>

    ```bash Empty Schemas
    miru release create \
      --version "v1.0.0" \
      --schemas ./linux/jsonschema/empty-schemas/
    ```

    ```bash Strict Schemas
    miru release create \
      --version "v1.0.0" \
      --schemas ./linux/jsonschema/strict-schemas/
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Windows">
    <CodeGroup>

    ```bash Empty Schemas
    miru release create \
      --version "v1.0.0" \
      --schemas ./windows/jsonschema/empty-schemas/
    ```

    ```bash Strict Schemas
    miru release create \
      --version "v1.0.0" \
      --schemas ./windows/jsonschema/strict-schemas/
    ```

    </CodeGroup>
  </Tab>
</Tabs>

Upon a successful creation, you'll see a confirmation message similar to the following:

```bash
$ miru release create \
  --version v1.0.0 \
  --schemas ./{os}/jsonschema/{schema-type}/

◐ Creating release v1.0.0

  ✓ Pushed git commit (new)
    1c7f7a8 · mirurobotics/getting-started

  ◐ Pushing schemas
    ✓ Mobility · SCH-D5nFP (new)
    ✓ Planning · SCH-37QAr (new)
    ✓ Communication · SCH-9WfCx (new)

✓ Created release v1.0.0
```
