Each device has its own deployment history, accessible by clicking the device on the [Devices page](https://app.mirurobotics.com/devices) and selecting the **Deployments** tab.

The list shows every deployment sent to the device, newest first, under a heading for
each release. Staged deployments aren't listed.

## View a deployment

To view a deployment, select it from the list. A panel will open with its details,
including its **Parent**, the deployment it was based on. Under **Configurations**, each
config instance shows how it changed since the parent: **ADDED**, **UNCHANGED**, or a
count of its changes.

## View a config instance

To view a config instance, click it under **Configurations**. It opens in **Diff** mode,
showing what changed since the parent deployment. Switch to **Read-only** to see the
file on its own.
