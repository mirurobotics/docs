## Properties

<ParamField path="name" type="string">
  <EditableBadge />

  The name of the manifest. Unique within the workspace.

  Example: `Picker v2`
</ParamField>

<ParamField path="components" type="[] Component">
  <EditableBadge />

  The [components](/cfg-mgmt/concepts/components) a device with this manifest should
  have. A manifest lists at most 100 components, each at most once.

  Examples: `kuka-arm`, `realsense-d435`
</ParamField>

## Create a hardware manifest  <PublisherBadge />

<PlatformUnsupportedBadge />

Navigate to the **Hardware Manifests** page and click **New Hardware Manifest** in the top right corner. Enter a name and choose its components.

## Edit a hardware manifest  <PublisherBadge />

<PlatformUnsupportedBadge />

Navigate to the **Hardware Manifests** page, click the ellipses (...) on the manifest you want to edit, and hit **Edit**. Changes apply to every device that uses the manifest.

## Delete a hardware manifest  <PublisherBadge />

<PlatformUnsupportedBadge />

Deleting a hardware manifest is only possible if no device uses it.

To delete a hardware manifest, click the ellipses (...) on the manifest you want to delete and select **Delete**.
