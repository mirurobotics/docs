## Properties

<ParamField path="name" type="string">
  <EditableBadge />

  A human-readable display name, derived from the slug, so `front-camera` becomes `Front Camera`.

  Examples: `Arm`, `Front Camera`, `Gripper`
</ParamField>

<ParamField path="slug" type="string">
  <ImmutableBadge />

  A unique, code-friendly identifier that devices report calibrations with.

  Slugs are immutable and must satisfy the following constraints:

  - Contain only lowercase letters, digits, and hyphens (`-`)
  - Start and end with a lowercase letter or digit
  - Contain between 1 and 32 characters

  Examples: `arm`, `front-camera`, `gripper`
</ParamField>

<ParamField path="roles" type="[] Role">
  The purposes the component fills on a device, such as their positions on a robot arm or the sides of a gripper.

  A device with two arms might report them as `aligner-1` and `aligner-2`.

  Examples: `front-left`, `front-right`, `back-left`, `back-right`
</ParamField>

<ParamField path="aspects" type="[] Aspect">
  The parts of a unit that are calibrated separately. A camera might have the aspects `intrinsics` and `extrinsics`.

  Examples: `intrinsics`, `extrinsics`
</ParamField>

Roles and aspects have a name and slug that follow the same rules as a component's. Their slugs only need to be unique within their component. Both are optional, so a device with one arm, calibrated one way, reports only the component.

## Create a component

<PlatformUnsupportedBadge />

Components, roles and aspects are created when a device first [reports a calibration](/cfg-mgmt/report-calibrations) that uses them. They can't be deleted, so a mistyped slug leaves a stray component behind. Use fixed slugs in your software.

A workspace can have up to 100 components, and each component up to 100 roles and 100 aspects. Past a limit, Miru rejects calibrations that would add a new one.

## Edit a component  <PublisherBadge />

<PlatformUnsupportedBadge />

To rename a component, role or aspect, open the component in the dashboard and edit its name. Slugs can't change, so devices are unaffected.
