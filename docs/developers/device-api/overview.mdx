The Miru Device API is a REST API with Server-Sent Events (SSE) streaming for programmatically interacting with the Miru Agent. 

The Device API is not available over the internet—it is only accessible to applications running on the same device as the Miru Agent. It is useful for manually refreshing configurations, retrieving current configurations, checking agent status, and receiving [real-time events](/developers/device-api/events) from applications running on your devices.

The Device API is distinct from the Miru [Platform API](/developers/platform-api/overview), which is a REST API for backend services and CI/CD pipelines to manage Miru resources.

## Getting started

How you connect depends on the device's operating system. Continue to [Authentication](/developers/device-api/authn) for the transport, base URL, and credentials on Linux and Windows. For a complete reference of all available API endpoints, visit the Device API Reference.
