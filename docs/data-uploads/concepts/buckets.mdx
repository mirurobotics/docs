## Properties

<ParamField path="name" type="string">
  <ImmutableBadge />

  The name of the bucket in your cloud storage account that uploads are written to. Bucket names must be unique within a Miru workspace. 

  Example: `robot-logs-bucket`
</ParamField>

<ParamField path="provider" type="enum">
  <ImmutableBadge />

  The cloud storage provider backing the bucket.

  Allowed values:
  - `gcs`
  - `aws`
</ParamField>

<ParamField path="config" type="Bucket Config">
  <MutableBadge />

  Provider-specific configuration, discriminated by `provider`. For `gcs`, see
  [GCS](/data-uploads/connect-a-bucket/gcs); for `aws`, see [AWS](/data-uploads/connect-a-bucket/aws).
</ParamField>

## View a bucket

<PlatformUnsupportedBadge />

To view a bucket, navigate to the
[Buckets page](https://app.mirurobotics.com/settings/buckets) and click the bucket. Its
details show the provider, its connection details (region, Role ARN and External ID for
AWS; service account for GCS), and when and by whom it was created.

<Frame>
  ![Buckets Page](https://assets.mirurobotics.com/docs/v04/images/buckets/list.png)
</Frame>

## Connect a bucket  <PublisherBadge />

<PlatformUnsupportedBadge />

To connect a bucket, follow the [GCS](/data-uploads/connect-a-bucket/gcs) or
[AWS S3](/data-uploads/connect-a-bucket/aws) guide.

## Verification

When you connect a bucket or change its Role ARN, Miru checks its access before saving:

- It uploads an empty object under `.miru/probe/`, then tries to delete it. With the
  write-only access the connect guides grant, the object stays in the bucket.
- For AWS buckets, it also confirms your role can't be assumed without the external ID.

If a check fails, the bucket isn't saved.

## Edit a bucket  <PublisherBadge />

<PlatformUnsupportedBadge />

Only an AWS bucket's **Role ARN** can be edited; GCS buckets have nothing to edit. To
upload to a different bucket, connect a new one.

To edit a bucket, click the ellipses **(...)** on the bucket and select **Edit**.

<Frame>
  ![Edit Bucket Menu](https://assets.mirurobotics.com/docs/v04/images/buckets/edit-menu.png)
</Frame>

A dialog will appear. Update the **Role ARN** and click **Save**.

<Note>
  Miru [verifies](#verification) the bucket again before saving.
</Note>

## Delete a bucket  <PublisherBadge />

<PlatformUnsupportedBadge />

Deleting a bucket is only possible if there are no file rules associated with the bucket. Otherwise, you must archive the bucket instead.

To delete a bucket, click the ellipses **(...)** on the bucket and select **Delete**.

<Frame>
  ![Delete Bucket Menu](https://assets.mirurobotics.com/docs/v04/images/buckets/delete-menu.png)
</Frame>

A confirmation dialog will appear. Click **Delete** to confirm.

## Archive a bucket  <PublisherBadge />

<PlatformUnsupportedBadge />

Archiving a bucket prevents any data uploads from being written to the bucket. However, it does not delete the bucket itself, and can be unarchived at any time.

To archive a bucket, click the ellipses **(...)** on the bucket and select **Archive**.

<Frame>
  ![Archive Bucket Menu](https://assets.mirurobotics.com/docs/v04/images/buckets/archive-menu.png)
</Frame>

A confirmation dialog will appear. Click **Archive** to confirm.
