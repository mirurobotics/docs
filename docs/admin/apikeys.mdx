API keys allow you to authenticate to the Miru [Platform API](/developers/platform-api/overview) as well as the Miru CLI in your [CI pipeline](/developers/ci/overview).

Your API keys carry many privileges, so be sure to keep them secure! Do not share your secret API keys in publicly accessible areas such as GitHub, client-side code, and so forth.

## Create an API key  <AdminBadge />

<PlatformUnsupportedBadge />

To create an API key, navigate to the
[API Keys page](https://app.mirurobotics.com/settings/secrets) and click **New API Key**
in the top right.

<Frame>
  ![New API Key Button](https://assets.mirurobotics.com/docs/v04/images/apikeys/create-button-v2.png)
</Frame>

The **Create API Key** page will open. Enter a name and an optional description, then
select the key's scopes: each row is a resource, and selecting `manage` covers the rest
of its row. Click **Create**. For a full reference of available scopes, see the Platform
API [Authorization](/developers/platform-api/authz) page.

<Frame>
  ![Create API Key Page](https://assets.mirurobotics.com/docs/v04/images/apikeys/create-page.png)
</Frame>

A dialog will appear with the new key. Copy it before clicking **Done**. It can never be
retrieved again; if you lose it, create a new one.

## View API keys

<PlatformUnsupportedBadge />

To view your workspace's API keys, navigate to the
[API Keys page](https://app.mirurobotics.com/settings/secrets). Each key is listed by
name; click a key to expand it and see its details:

- **Last used:** when the key was last used, or Never used.
- **Description:** what the key is for, or None.
- **Created:** when the key was created.
- **Created by:** who created the key.
- **Scopes:** what the key can access.

<Frame>
  ![API Key Details](https://assets.mirurobotics.com/docs/v04/images/apikeys/details.png)
</Frame>

## Edit an API key  <AdminBadge />

<PlatformUnsupportedBadge />

To edit an API key, click the ellipses **(...)** on the key, or right-click it, and
select **Edit**.

<Frame>
  ![Edit API Key Menu](https://assets.mirurobotics.com/docs/v04/images/apikeys/edit-menu.png)
</Frame>

The **Edit API Key** page will open. Change the key's name, description, or scopes, then
click **Save**. The key itself doesn't change, so anything using it keeps working with
the new scopes.

<Frame>
  ![Edit API Key Page](https://assets.mirurobotics.com/docs/v04/images/apikeys/edit-page.png)
</Frame>

## Delete an API key  <AdminBadge />

<PlatformUnsupportedBadge />

Deleting an API key immediately revokes it. Attempting to authenticate with a deleted API key will fail. Furthermore, deleting an API key is irreversible. Once an API key is deleted, it cannot be recovered.

To delete an API key, click the ellipses **(...)** on the key, or right-click it, and
select **Delete**.

<Frame>
  ![Delete API Key Menu](https://assets.mirurobotics.com/docs/v04/images/apikeys/delete-menu.png)
</Frame>

A confirmation dialog will appear. Hit **Delete** to confirm the deletion.
