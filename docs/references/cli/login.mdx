Authenticate the CLI on your development machine by storing a token locally.

`login` is interactive: it opens a browser so you can approve access. For non-interactive use such as [CI pipelines](/developers/ci/overview), scripts, and AI agents, authenticate with the `MIRU_API_KEY` environment variable instead — see [Authentication](/developers/cli/authentication#api-key).
