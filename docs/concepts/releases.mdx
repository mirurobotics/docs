## View a release

<PlatformApiBadge endpoint="releases/get" />

To view a release, click into it from the
[Releases page](https://app.mirurobotics.com/releases) and open the **Overview** tab:

- **Active** and **Staged:** how many devices are on this release, and how many have a
  deployment staged for it.
- **Schemas:** the release's config schemas. Click one to view it.
- **File Rules:** the release's
  [file rules](/data-uploads/concepts/file-rules/overview#view-a-file-rule).

<Frame>
  ![Release Overview](https://assets.mirurobotics.com/docs/v04/images/releases/overview-tab.png)
</Frame>

## Duplicate a release  <PublisherBadge />

Duplicating a release creates a new release with the same config schemas and git information as the original.

Of course, since releases require a unique version, the duplicated release must have a *different version* from the original release.

Duplicating a release does not duplicate the release's deployments—only the release, its schemas, and git information are duplicated.

To duplicate a release, click the ellipses **(...)** on the release, or right-click it,
and select **Duplicate**.

<Frame>
  ![Release Ellipses Dropdown](https://assets.mirurobotics.com/docs/v04/images/releases/duplicate-menu.png)
</Frame>

A dialog will appear—input the new version name and hit **Create**.

## Archive a release  <PublisherBadge />

<PlatformUnsupportedBadge />

Archiving a release hides it from the releases list and restricts deployments to *only* devices currently running that release.

New devices cannot be deployed with an archived release and existing devices cannot switch to or rollback to an archived release.

Archiving a release retains its config schemas and deployment history, and releases can be unarchived at any time.

To archive a release, click the ellipses **(...)** on the release, or right-click it, and
select **Archive**.

<Frame>
  ![Archive Release Ellipses Dropdown](https://assets.mirurobotics.com/docs/v04/images/releases/archive-menu.png)
</Frame>

A dialog will appear. Hit **Archive** to confirm the archive.

## Unarchive a release

<PlatformUnsupportedBadge />

Unarchiving a release makes it available for any device to deploy from it again.

Find the release among the archived releases, click the ellipses **(...)**, or
right-click it, and select **Unarchive**.

<Frame>
  ![Unarchive Release Ellipses Dropdown](https://assets.mirurobotics.com/docs/v04/images/releases/unarchive-menu.png)
</Frame>

A dialog will appear. Hit **Unarchive** to confirm the unarchive.

## Delete a release  <AdminBadge />

<PlatformUnsupportedBadge />

Deleting a release is only possible if no deployments have been delivered to any device with that release. Otherwise, the release cannot be deleted.

To delete a release, click the ellipses **(...)** on the release, or right-click it, and
hit **Delete**.

<Frame>
  ![Release Ellipses Dropdown](https://assets.mirurobotics.com/docs/v04/images/releases/delete-menu.png)
</Frame>

A confirmation dialog will appear. Hit **Delete** to confirm the deletion.
