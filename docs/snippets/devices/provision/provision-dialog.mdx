The dialog will present a pre-authenticated command that invokes the `miru-agent` binary with a short-lived token (5 minutes) to provision the device for your workspace. Select the tab for the device's operating system.

<Frame>
  ![Provision Miru Agent Dialog](https://assets.mirurobotics.com/docs/v04/images/devices/provisioning/provision-dialog-v2.png)
</Frame>

    <CmdBreakdown />

    To provision the device, copy the command from the dialog and paste it into the terminal of the machine you want to provision.
  </Tab>
  <Tab title="Windows">
    The command can be broken into the following components:

    <CmdBreakdownWindows />

    To provision the device, copy the command from the dialog and paste it into PowerShell opened with **Run as administrator** on the machine you want to provision.
  </Tab>
