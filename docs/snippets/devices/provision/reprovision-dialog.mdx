The dialog will present a pre-authenticated command that invokes the `miru-agent` binary with a short-lived (5 minutes) token to reprovision the device for your workspace. Select the appropriate operating system.

    </Frame>

    The command can be broken into the following components:

    <CmdBreakdownLinux />

    To reprovision the device, click **Copy command** in the dialog and paste the command into the terminal of the machine you want to reprovision.
  </Tab>
  <Tab title="Windows">
    <Frame>
      ![Reprovision Dialog for Windows](https://assets.mirurobotics.com/docs/v04/images/devices/provisioning/reprovision-dialog-windows.png)

    The command can be broken into the following components:

    <CmdBreakdownWindows />

    To reprovision the device, click **Copy command** in the dialog and paste the command into PowerShell opened with **Run as administrator** on the machine you want to reprovision.
  </Tab>
