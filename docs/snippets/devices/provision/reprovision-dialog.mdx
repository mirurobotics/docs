The dialog will present a pre-authenticated command that invokes the `miru-agent` binary with a short-lived (5 minutes) token to reprovision the device for your workspace. Make sure to follow the instructions for the device's operating system.

<Frame>
  ![Reprovision Miru Agent Dialog](https://assets.mirurobotics.com/docs/v04/images/devices/provisioning/reprovision-dialog.png)
</Frame>

<Tabs>
  <Tab title="Linux">
    The command can be broken into the following components:

    <CmdBreakdownLinux />

    To reprovision the device, copy the command from the dialog and paste it into the terminal of the machine you want to reprovision.
  </Tab>
  <Tab title="Windows">
    The command can be broken into the following components:

    <CmdBreakdownWindows />

    To reprovision the device, copy the command from the dialog and paste it into PowerShell opened with **Run as administrator** on the machine you want to reprovision.
  </Tab>
</Tabs>
