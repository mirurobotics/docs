- `$env:MIRU_PROVISIONING_TOKEN = "<token>"` sets the token that authenticates the request.
- `& "$env:ProgramW6432\Miru\Agent\miru-agent.exe" provision` executes the `miru-agent` binary with the `provision` command.
- `Remove-Item Env:MIRU_PROVISIONING_TOKEN` clears the token from the PowerShell session.
