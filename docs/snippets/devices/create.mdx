Navigate to the [Devices page](https://app.mirurobotics.com/devices).

<Frame>
   ![Devices Create Page](https://assets.mirurobotics.com/docs/v04/images/devices/create-page-v2.png)
</Frame>

Click the **+ Device** button in the top right corner. Enter a name for your device.
Optionally, add a description and choose a [group](/concepts/groups/overview) for the
device. Then click **Create**.
