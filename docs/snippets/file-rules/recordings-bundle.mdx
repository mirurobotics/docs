```yaml highlight={4,10} nocopy
name: Recordings

source:
  glob: "/data/recordings/{recording}/*"

upload:
  collection_slug: recordings
  bucket: my-uploads-bucket
  path: "{device_name}/{bundle_id}/{upload_id}/{file_name}"
  bundle: [recording]
```

Using this rule, all files in the `run_42` folder are bundled together:
