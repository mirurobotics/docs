  <Tab title="Windows">
    The Miru Agent for Windows is distributed as an MSI installer.

    Windows is only supported for Miru Agent [v0.11.0](/changelog/agent#v0-11-0) and later. Earlier releases do not include an MSI installer.

    <Tabs>
      <Tab title="Manual">
        <Steps>
          <Step title="Download">

            Find your desired release version from the [releases page](https://github.com/mirurobotics/agent/releases) on GitHub, expand the **Assets** section, and download `miru-agent-<version>.msi`.
          </Step>
          <Step title="Install">

            Double-click the MSI in your Downloads folder and follow the installer. It registers and starts the `miru-agent` Windows service.
          </Step>
        </Steps>
      </Tab>
      <Tab title="Command line">
        <Steps>
          <Step title="Download and install">

            Open PowerShell with **Run as administrator** and run the following, replacing `<version>` with the agent version to install, such as `0.11.0`. The command downloads the MSI from the [releases page](https://github.com/mirurobotics/agent/releases) and installs it silently.

            ```powershell PowerShell
            $version = "<version>"; `
            Invoke-WebRequest "https://github.com/mirurobotics/agent/releases/download/v$version/miru-agent-$version.msi" -OutFile "$env:TEMP\miru-agent.msi"; `
            Start-Process msiexec.exe -ArgumentList "/i `"$env:TEMP\miru-agent.msi`" /qn /norestart" -Wait
            ```
          </Step>
          <Step title="Verify">

            Confirm the `miru-agent` service is running.

            ```powershell PowerShell
            Get-Service miru-agent
            ```

            The `Status` column shows `Running`. If the service is missing or not running, run the install again with `/l*v C:\miru-agent-install.log` added to the `msiexec.exe` arguments and check that log.
          </Step>
        </Steps>
      </Tab>
    </Tabs>
  </Tab>
