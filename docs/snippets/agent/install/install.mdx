  <Tab title="Windows">
    The Miru Agent for Windows is distributed as an MSI installer. 
    
    Windows is only supported for Miru Agent [v0.11.0](/changelog/agent#v0-11-0) and later. Earlier releases do not include an MSI installer.

    <Tabs>
      <Tab title="Manual">
        <Steps>
          <Step title="Download">

            Find your desired release version from the [releases page](https://github.com/mirurobotics/agent/releases) on GitHub, expand the **Assets** section, and download `miru-agent-<version>.msi`.
          </Step>
          <Step title="Install">

            Double-click the MSI in your Downloads folder and follow the installer. It registers and starts the `miru-agent` Windows service.
          </Step>
        </Steps>
      </Tab>
      <Tab title="Programmatic">
        <Steps>
          <Step title="Download">

            Find your desired release version from the [releases page](https://github.com/mirurobotics/agent/releases) on GitHub, expand the **Assets** section, and download `miru-agent-<version>.msi`.
          </Step>
          <Step title="Install">

            Open PowerShell with **Run as administrator** and run the installer, replacing the paths with your own.

            ```powershell
            msiexec /i "C:\path\to\miru-agent-<version>.msi" `
              /qn `
              /norestart `
              /l*v "C:\path\to\miru-agent-install.log"
            ```

            `$LASTEXITCODE` is `0` when the agent is installed. `3010` means the agent is installed and Windows must be restarted. For any other exit code, check the log file.
          </Step>
        </Steps>
      </Tab>
    </Tabs>
  </Tab>
