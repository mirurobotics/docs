  <Tab title="Windows">
    The Miru Agent for Windows is distributed as an MSI installer.

    <Steps>
      <Step title="Download">
        Open the [latest release](https://github.com/mirurobotics/agent/releases/latest) on GitHub, expand the **Assets** section, and download `miru-agent-<version>.msi`.
      </Step>
      <Step title="Install">

        Open PowerShell with **Run as administrator** and run the installer, replacing the paths with your own.

        ```powershell
        $msi = "C:\path\to\miru-agent-<version>.msi"
        $log = "C:\path\to\miru-agent-install.log"
        $p = Start-Process msiexec.exe -ArgumentList '/i',"`"$msi`"",'/qn','/norestart','/l*v',"`"$log`"" -Wait -PassThru
        $p.ExitCode
        ```

        An exit code of `0` means the agent is installed. An exit code of `3010` means the agent is installed and Windows must be restarted. For any other exit code, check the log file.

        Double-clicking the MSI runs the interactive installer instead.

        The installer registers and starts the `miru-agent` Windows service.
      </Step>
      <Step title="Verify">

        Confirm the service is running.

        ```powershell
        Get-Service miru-agent
        ```

        The `Status` column shows `Running`.
      </Step>
    </Steps>
  </Tab>
