<Tabs>
  <Tab title="Linux">
    The `miru-agent` package can be upgraded via `apt` or by manually downloading the Debian package from GitHub.

    <Tabs>
      <Tab title="APT">
        Upgrade the existing `miru-agent` via `apt`.

        ```bash
        sudo apt-get update
        sudo apt-get install miru-agent
        ```

        <Tip>
          Upgrade to a specific version with `sudo apt-get install miru-agent=<version>` (e.g. `0.7.0`, `0.8.0`, etc.).
        </Tip>
      </Tab>
      <Tab title="Manual">
        Manual installations do not have a native upgrade mechanism. Simply repeat the [installation steps](#install) to upgrade to the latest version.
      </Tab>
    </Tabs>
  </Tab>
  <Tab title="Windows">
    Run the [install command](#install) with a newer MSI. The installer upgrades in place and keeps `%ProgramData%\Miru`, so the device stays provisioned.

    Installing an older MSI over a newer version fails. To downgrade, you must first [uninstall](#uninstall) the agent and then install the older version.
  </Tab>
</Tabs>
