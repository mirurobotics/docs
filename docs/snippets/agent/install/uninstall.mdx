<Tabs>
  <Tab title="Linux">
    Remove the Debian package.

    ```bash
    sudo apt-get purge miru-agent
    ```

    If installed via `apt`, you can also remove the apt source and keyring.

    <RemoveApt />

    <Info>
        The signing key at `/etc/apt/keyrings/miru-archive-keyring.gpg` is shared with the Miru CLI. Only remove it if you have also uninstalled the Miru CLI.
    </Info>
  </Tab>
  <Tab title="Windows">
    You can uninstall the **Miru Agent** from **Settings > Apps > Installed apps**.
    
    To programmatically uninstall the agent, run the following from PowerShell opened with **Run as administrator**, using the MSI of the installed version.

    ```powershell
    Start-Process msiexec.exe -ArgumentList '/x','"C:\path\to\miru-agent-<version>.msi"','/qn','/norestart' -Wait -PassThru
    ```

    Uninstalling keeps `%ProgramData%\Miru`, which holds the agent's settings, device identity, keys, and logs. For a complete removal, delete this directory after uninstalling the agent.

    ```powershell
    Remove-Item -Recurse -Force "$env:ProgramData\Miru"
    ```
  </Tab>
</Tabs>
