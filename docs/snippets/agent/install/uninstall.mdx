<Tabs>
  <Tab title="Linux">
    Remove the Debian package.

    ```bash
    sudo apt-get purge miru-agent
    ```

    If installed via `apt`, you can also remove the apt source and keyring.

    <RemoveApt />

    <Info>
        The signing key at `/etc/apt/keyrings/miru-archive-keyring.gpg` is shared with the Miru CLI. Only remove it if you have also uninstalled the Miru CLI.
    </Info>
  </Tab>
  <Tab title="Windows">
    <Tabs>
      <Tab title="Manual">
        Uninstall the **Miru Agent** from **Settings > Apps > Installed apps**.
      </Tab>
      <Tab title="Programmatic">
        Open PowerShell with **Run as administrator** and run the following. It looks up the installed Miru Agent and uninstalls it silently, so you don't need the original MSI.

        ```powershell PowerShell
        $app = Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*" | Where-Object DisplayName -eq "Miru Agent"; `
        Start-Process msiexec.exe -ArgumentList "/x $($app.PSChildName) /qn /norestart" -Wait
        ```

        To confirm the agent is removed, run `Get-Service miru-agent`, which reports that it cannot find a service named `miru-agent`.
      </Tab>
    </Tabs>

    Uninstalling keeps `%ProgramData%\Miru`, which holds the agent's settings, device identity, keys, and logs, and the `Miru Agent Users` group and its members. For a complete removal, delete both after uninstalling the agent:

    ```powershell PowerShell
    Remove-Item -Recurse -Force "$env:ProgramData\Miru"; `
    Remove-LocalGroup "Miru Agent Users"
    ```
  </Tab>
</Tabs>
