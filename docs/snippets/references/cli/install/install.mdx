The CLI is available on macOS, Linux, and Windows (x64).

<Tabs>
  <Tab title="macOS">
    Install via Homebrew.

    ```bash
    brew install mirurobotics/cli/miru
    ```

    <Info>
      If you are not seeing the latest CLI version, refresh Homebrew with `brew update`.
    </Info>
  </Tab>

  <Tab title="Linux">

    The CLI is distributed to Linux as a Debian package. Other package formats are not yet supported.

    We recommend using `apt` to install the CLI. However, you can manually install the Debian package by downloading it from GitHub and installing it with `dpkg`.

    <Tabs>
      <Tab title="APT">
        <Steps>
          <Step title="Set up">

            Set up Miru's `apt` repository.
            <SetupApt />

          </Step>
          <Step title="Install">

            After configuring the `apt` repository, install the CLI.

            ```bash
            sudo apt-get update
            sudo apt-get install miru-cli
            ```

            <Tip>
                Install a specific version with `sudo apt-get install miru-cli=<version>` (e.g. `0.9.1`, `0.10.0`, etc.).
            </Tip>
          </Step>
        </Steps>
      </Tab>

      <Tab title="Manual">
        <Steps>
          <Step title="Download">
            <GithubDownload />
          </Step>
          <Step title="Install">
            After downloading the package, install it using `dpkg`.

            ```bash
            sudo dpkg -i <...>.deb
            ```
          </Step>
        </Steps>
      </Tab>
    </Tabs>
  </Tab>

  <Tab title="Windows">
    The CLI is distributed to Windows as a zip archive. Run these commands in PowerShell; administrator rights are **not** required.

    <Steps>
      <Step title="Download and extract">
        Download the latest release from [GitHub](https://github.com/mirurobotics/cli/releases/latest) and extract `miru.exe`.

        ```powershell PowerShell wrap
        Invoke-WebRequest https://github.com/mirurobotics/cli/releases/latest/download/cli_Windows_x86_64.zip -UseBasicParsing -OutFile "$env:TEMP\miru.zip"; Expand-Archive "$env:TEMP\miru.zip" "$env:LOCALAPPDATA\Programs\Miru\CLI" -Force; Remove-Item "$env:TEMP\miru.zip"
        ```
      </Step>
      <Step title="Verify the signature">
        Check that `miru.exe` has a valid code signature. The status should be `Valid`, and the subject should start with `CN="Clips AI, Inc."`, Miru's official legal entity. If either doesn't match, delete `miru.exe` and stop.

        ```powershell PowerShell wrap
        Get-AuthenticodeSignature "$env:LOCALAPPDATA\Programs\Miru\CLI\miru.exe" | Format-List Status, @{ Label = 'Subject'; Expression = { $_.SignerCertificate.Subject } }
        ```
      </Step>
      <Step title="Add to PATH">
        Add the folder to your user `PATH`, then open a new PowerShell window.

        ```powershell PowerShell wrap
        $dir = "$env:LOCALAPPDATA\Programs\Miru\CLI"; $path = [Environment]::GetEnvironmentVariable('Path', 'User'); if (($path -split ';') -notcontains $dir) { [Environment]::SetEnvironmentVariable('Path', (@($path -split ';' | Where-Object { $_ }) + $dir) -join ';', 'User') }
        ```
      </Step>
    </Steps>
  </Tab>
</Tabs>
