Config files are read from or written to your local machine relative to the path specified by `--root` in the CLI command. When not specified, `--root` defaults to the current directory.

Below are examples of where each config file is on your local machine when using the CLI.

<Tabs>
  <Tab title="Linux device paths">

    Linux paths are straightforward—they drop their leading `/` and are appended to the `--root` path.

    | `--root` | Config instance path | Local path |
    |----------|-------------|------------|
    | `./robot-42-fs` | `/srv/app.json` | `./robot-42-fs/srv/app.json` |
    | `/` | `/srv/app.json` | `/srv/app.json` |
  </Tab>
  <Tab title="Windows device paths">

    Windows paths are a bit more complex. 
    
    When `--root` is the root of the file's drive, the drive letter is left out. However, when `--root` is not the root of the file's drive, the drive letter is included as its own top-level folder.

    | `--root` | Config instance path | Local path |
    |----------|-------------|------------|
    | `.\robot-42-fs` | `C:\srv\app.json` | `.\robot-42-fs\C\srv\app.json` |
    | `C:\` | `C:\srv\app.json` | `C:\srv\app.json` |
  </Tab>
</Tabs>

- **Config instance path**: the file path specified in the [config instance](/cfg-mgmt/concepts/config-instances#param-file-path).
- **Local path**: the path on your local machine when interacting with the CLI.
