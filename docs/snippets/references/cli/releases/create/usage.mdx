<Tabs>

  <Tab title="Schema Directory">
    Use the `--schemas` flag to specify a directory containing the schemas to include in the release.

    ```bash
    miru release create \
      --version {version} \
      --schemas {/path/to/schemas/directory/}
    ```
  </Tab>

  <Tab title="Schema Files">
    Use the `--schema` flag to specify schema files to include in the release.

    ```bash
    miru release create \
      --version {version} \
      --schema {path/to/schema1.yaml} \
      --schema {path/to/schema2.yaml}
    ```
  </Tab>

  <Tab title="File Rules">
    Use the `--file-rule` flag to include [file rule](/data-uploads/define-file-rules) files in the release, or `--file-rules` for a directory of rule files. File rules ride along with the release's config schemas.

    ```bash
    miru release create \
      --version {version} \
      --schemas {/path/to/schemas/directory/} \
      --file-rule {path/to/rule1.yaml} \
      --file-rules {/path/to/file/rules/directory/}
    ```
  </Tab>

</Tabs>
