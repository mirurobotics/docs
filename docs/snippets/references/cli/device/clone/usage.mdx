<Tabs>
  <Tab title="Current directory">

    By default, cloning a device writes the config files to the current directory.

    ```bash
    miru device clone {device-name}
    ```
  </Tab>

  <Tab title="Custom root">

    Use the `--root` flag to write the config files to a custom root directory.

    <CodeGroup>

    ```bash Bash
    miru device clone {device-name} \
      --root ./robot-42-fs
    ```

    ```powershell PowerShell
    miru device clone {device-name} `
      --root .\robot-42-fs
    ```

    </CodeGroup>
  </Tab>

  <Tab title="Device paths">

    Use `--root /` to write config files to the exact location they are written to on production devices.

    <CodeGroup>

    ```bash Bash
    miru device clone {device-name} \
      --root /
    ```

    ```powershell PowerShell
    miru device clone {device-name} `
      --root /
    ```

    </CodeGroup>
  </Tab>
</Tabs>

<Tip>
  Use `sudo miru ...`, or run PowerShell as Administrator, to write config files to restricted paths.
</Tip>
