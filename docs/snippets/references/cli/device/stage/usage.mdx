<Tabs>
  <Tab title="Current directory">

    By default, staging a device reads the config files from the current directory.

    <CodeGroup>

    ```bash Unix
    miru device stage {device-name} \
      --release {version} \
      --description {description}
    ```

    ```pwsh PowerShell
    miru device stage {device-name} `
      --release {version} `
      --description {description}
    ```

    </CodeGroup>
  </Tab>

  <Tab title="Custom root">
    Use the `--root` flag to read the config files from a custom root directory.

    <CodeGroup>

    ```bash Unix highlight={4}
    miru device stage {device-name} \
      --release {version} \
      --description {description} \
      --root ./robot-42-fs
    ```

    ```pwsh PowerShell highlight={4}
    miru device stage {device-name} `
      --release {version} `
      --description {description} `
      --root ./robot-42-fs
    ```

    </CodeGroup>
  </Tab>
</Tabs>

<Tip>
  Use `sudo miru ...`, or run PowerShell as Administrator, to read config files from restricted paths.
</Tip>
