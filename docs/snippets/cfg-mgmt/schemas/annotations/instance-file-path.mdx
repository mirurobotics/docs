<ParamField path="instance file path">
  The instance file path is the absolute file system path where config instances for this schema are written on the device.

  This annotation is optional and defaults to `/srv/miru/configs/{config-type-slug}.{instance-format}`. The default is a Linux path, so schemas for Windows devices must set an explicit path such as `C:\ProgramData\Miru\configs\mobility.json`.

  To share the same schema amongst multiple config instances, declare [instance slots](/cfg-mgmt/concepts/schemas/annotations#param-instance-slots) instead.

  <CodeGroup>

  ```yaml JSON Schema
  x-miru-instance-filepath: "/srv/miru/configs/{config-type-slug}.json"
  ```

  ```cue CUE
  @miru(instance_filepath="/srv/miru/configs/mobility.json")
  ```

  ```yaml Opaque
  instance_filepath: 'C:\ProgramData\Miru\configs\communication.yaml'
  ```

  </CodeGroup>

  <Tabs>
    <Tab title="Linux">
      The Miru Agent ships with out-of-the-box access to `/srv/miru`. Any local account can read configs deployed to `/srv/miru`.

      <Warning>
         To deploy configs to a custom directory, visit [File system access](/developers/agent/filesys-access/linux#configs).
      </Warning>

      - `/srv/miru/configs/mobility.json`
      - `/home/myapp/configs/communication.yaml`

    </Tab>
    <Tab title="Windows">
      The Miru Agent ships with out-of-the-box access to `%ProgramData%\Miru\configs`. 
      
      Only members of the local `Miru Agent Users` group can read configs deployed to `%ProgramData%\Miru\configs`. See [File system access](/developers/agent/filesys-access/windows#configs).

      <Warning>
         To deploy configs to a custom directory, please visit the [File system access](/developers/agent/filesys-access/windows#configs) page.
      </Warning>

      - `C:\ProgramData\Miru\configs\mobility.json`
      - `C:\ProgramData\MyApp\configs\communication.yaml`
    </Tab>
  </Tabs>
</ParamField>
